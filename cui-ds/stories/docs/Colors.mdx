# Color System

CUI Design System uses a structured color palette with 5 color scales (Blue, Gray, Green, Orange, Red), each with 10 shades (0–900). Colors are themeable across 4 brand modes.

## Semantic Tokens

Semantic tokens map to specific UI purposes and change per brand theme.

| Token | Purpose | Default Value |
|-------|---------|---------------|
| `brand.primary` | Primary brand color | `#7146b5` |
| `brand.secondary` | Light brand tint | `#eee6f5` |
| `text.primary` | Main text | `#121212` |
| `text.secondary` | Supporting text | `#424242` |
| `text.tertiary` | Placeholder/muted | `#888888` |
| `status.positive` | Success states | `#008000` |
| `status.negative` | Error states | `#d63333` |
| `status.info` | Information | `#2b5cbb` |
| `status.alert` | Warning states | `#ae7028` |
| `surface.neutral` | Default background | `#ffffff` |
| `surface.card` | Card background | `#f7f7f7` |

## Theme Modes

The color system supports 4 brand themes. Switch between them using the toolbar above.

- **Brand Default** - Purple (`#7146b5`)
- **Redstone Credit Union** - Red (`#c41230`)
- **GoldenOne Credit Union** - Green (`#005f3b`)
- **Georgia Own Credit Union** - Blue (`#1a3a6b`)
