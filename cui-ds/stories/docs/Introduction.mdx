CUI (Clutch User Interface) is a comprehensive design system built for credit union digital products. It provides a consistent, accessible, and themeable set of components, tokens, and patterns.

## Key Features

- **Multi-brand theming** — 4 brand themes switchable via the toolbar (paintbrush icon)
- **30 components** — From buttons to tables, covering all common UI patterns
- **Design tokens** — Colors, typography, spacing, and radius systemized as code
- **Built with React + TypeScript + styled-components**

## Structure

### Foundations
- **Colors** — 5 color scales with 10 shades each + semantic tokens
- **Typography** — Albert Sans type system with 9 sizes and 4 weights
- **Spacing & Radius** — Consistent spatial scale from 2px to 32px

### Components
- **Base** — Button, Badge, Card, Avatar, Chip, Link, Divider, Tooltip
- **Forms** — Input, Select, Checkbox, Radio, Switch, TextArea
- **Feedback** — Alert, Callout, Spinner, Skeleton, LinearProgress, Snackbar, Notification
- **Layout** — Modal, Tabs, Pagination, Breadcrumbs, Table, List, Popover, EmptyState, Overlay
