# Typography

CUI Design System uses **Albert Sans** as its primary typeface. The type scale is designed for clarity in financial interfaces.

## Font Family

```
'Albert Sans', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif
```

## Font Weights

| Weight | Value | Usage |
|--------|-------|-------|
| Light | 300 | Decorative / large display |
| Regular | 400 | Body text |
| Medium | 500 | Headings, emphasis |
| Bold | 700 | CTAs, labels, strong emphasis |
